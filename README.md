# 📱 Overview

SafeMind is  mental wellness and stress management application built exclusively for Apple platforms.

Instead of simply tracking moods, SafeMind understands how a user feels through a quick daily check-in and instantly provides personalized guidance including breathing exercises, journaling, acupressure, focus music, and actionable wellness recommendations.

The entire mood analysis runs **on-device using Apple's Foundation Models**, ensuring privacy while delivering intelligent and contextual responses.

# 🔒 Privacy

SafeMind is designed with privacy at its core.

- Mood analysis happens completely on-device.
- Personal emotional data is never sent to external AI services.
- Authentication and profile synchronization use Supabase.
- Users remain in control of their wellness information.
